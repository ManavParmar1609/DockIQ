Scope: the whole DockIQ app shell and every screen (Operate), plus the landing page (Persuade). Visual world only; routes, flows, data and behaviour are unchanged. Dark only (the owner's reference replaces the earlier light-only instruction).

Audience and job: dock workers on tablets (gloved, glare, dim light), supervisors triaging a zone, Quality holding product. Proof: the product's own screens with fictional, marked-simulated data.

## Direction contract

THESIS: The owner's GSAP reference — an animated chalkboard in a design studio — applied to a dock: one near-black stage where carved cream type and colour-coded highlighters file the work. Refuses the light SaaS dashboard: no white cards, no filled grey buttons, colour only where it files or alarms.

OWN-WORLD: #0e100f stage, #171917 surface step, cream #fffce1 ink, #42433d rules; 100px pills — cream hairline secondaries and one green-gradient-stroked primary that fills on hover/press; green highlighter blocks for your place (active nav, selected tab, your chat words); pink, blue, lilac file zones, groups and sections; orange marks simulated data; `{ }` bracket notes beside titles. Type: Host Grotesk (Mori/Messina stand-in) for everything, Source Serif 4 display optical size (Untitled Serif stand-in) for panel and section titles ≥20px, Geist Mono telemetry. Severity keeps red/amber/citron with word and shape.

STORY: The worker sees what to do next and can close what they fixed; the supervisor sees what needs them in order; Quality sees what is held and why.

FIRST VIEWPORT: App — the rail with the gradient mark and a bracketed role, the page title carved at 44–66px wiping up, a bracketed context note, then the task's primary object. Landing — the green announcement bar, a two-line 184px headline indented like the reference with a pink clover and lilac squiggle drifting through it, the bracketed note left and the gradient-stroked CTA right.

FORM: Owner-pinned GSAP reference (video + spec) with the owner's serif request (no concept roll: the brief named the world). Signature motion: words lighting as they scroll, highlighter montage, drifting soft shapes, the green rising through the primary pill. Seed key: owner-pinned-gsap.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, and DESIGN.md.
